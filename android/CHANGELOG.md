# Changelog

与电脑端 ScreenKit 配套的安卓客户端「PC文件传输」（`com.whj.screenkit`）。

## unreleased

### 新增

- 桌面两个启动入口：**传文件**（原文件/文本同步）、**投屏**（扫描电脑 / 手动 IP / USB，MediaProjection 推画面到 ScreenKit）。

### 变更

- 拍照压缩改由电脑 **参数设置 → 接口** 配置。连接成功后从 `info` 写入本地缓存，拍照时使用。手机参数设置里不再改这些项。
- 手机 WiFi 投屏：点选电脑后可直接开始；画面走 HTTP `/cast`（1224）。`CastService.broadcastStat` 递归写错导致 StackOverflow 闪退，已改回发广播。
- USB 配件：先写出 hello 再 `startRead()` 读回包；ping 用队列异步回 pong，避免读线程阻塞。
- USB 配件：AOA bulk 桥接进行中电脑暂停 `adb reverse`；**USB 投屏(adb)** 在助手空等时恢复 reverse（修复此前 probe 一直失败）。
- 调试：`am start … --ez scst_adb_probe true` 只测 `127.0.0.1:1224` 是否通（不截屏）。
- WiFi 投屏：握手改为 **先 `startCtrl` 再发 hello**，避免 PC 回包早于读线程导致 `hello ack=false`；`CastWifiProbe` + `--ez scst_wifi_probe true` 可测 WS/hello（需 `--es scst_ip 电脑局域网IP`）。
- USB 配件：整包读取后再拆 SCST 帧。按 9 字节头去读会丢掉同一 USB 包里剩下的 hello/视频，电脑窗口一直黑。
- 主界面 **投屏** 按钮放在连接状态卡片上，未连接电脑时也显示。停止投屏时立刻把 `bye` 写入 USB，让电脑关窗。
- 主界面和投屏页显示 **USB配件** 状态（已连接 / 等待中 / 未连接）。电脑打开配件后只提示，需在投屏页点 **USB** 才开始。插上配件不再自动投屏。电脑关掉画面会发 `bye`，手机停止投屏。
- 拍照上传先申请相机权限再打开相机。未授权时不再直接拉起相机导致闪退。
- 投屏页按常见顺序重排：先确认电脑 IP，再 **开始投屏**。投屏中才显示 **停止** 和 **熄屏**。USB 投屏单独放在下方。打开页面不再自动扫描。
- 手机发 hello，电脑回 hello 后才开始投屏并显示「投屏中」；电脑此时才弹窗。未收到应答则提示「电脑未打开 ScreenKit」。
- 扫描电脑与传文件共用 UDP 17531；画面走 HTTP `/cast`（默认 1224），不再连 19519/19520。
- 停止时向电脑 `GET /api/cast/stop`（等最多 400ms），画面窗立刻关。
- USB 配件测试画面：手机自绘 640×360 动态块（不截屏）只走 AOA bulk（`scst_usb_pat`），不用 adb reverse、不用 WiFi。
- 横屏按当前画质重绑编码器（保留 VirtualDisplay），不再只发方向裁切导致分辨率骤降；失败仍回落裁切。
- USB 投屏：电脑开接收后自动拉起配件助手，不必再点 **USB配件**。助手一场结束后继续等，不再每 8 秒杀掉正在跑的助手。
- **USB 投屏**等待配件 12 秒，没有则改走 USB 网络共享（通知栏打开网络共享）。
- 投屏扫描列表点选后高亮（蓝底描边），状态栏显示已选电脑；仅一台时自动选中。
- 「传文件」与「投屏」分属独立任务栈，可同时打开、在最近任务里来回切。
- USB 投屏改为 USB 配件（AOA），不再探测 `adb reverse` / 127.0.0.1；无需 USB 调试。无配件时改为探测 USB 网络共享。
- 投屏采集改到主线程创建 VirtualDisplay，并先发 SPS/PPS，避免 WiFi 黑屏。
- WiFi 投屏：编码缓冲立刻释放，发送线程只发最新视频帧，避免卡在某一画面。
- 投屏声音：音频包不再被视频挤掉；停止时发 `bye`。
- USB 投屏：无配件时在 USB 网卡上监听，等电脑连入（不反向连电脑，避免 Windows 公用网络防火墙）。
- 打开投屏界面即扫描电脑。
- 进入投屏页 onResume 自动扫描；发现用临时端口，避免绑死 19518。
- 投屏状态显示类型 wifi / usb / usb(adb)；去掉 USB 说明行；手动 IP 自动填入连上的电脑地址。
- 连接失败只提示「连接失败」，不再把 abstract/IOException 堆在状态栏。
- 按屏幕比例编码，旋转重建采集，减轻进 B 站闪退。
- USB 投屏无网络共享时回落到 adb。
- 横屏只发方向、不重建编码器，避免闪退。
- **USB 投屏**不再走 adb，只配件或网络共享。
- **USB 投屏**等待 USB 配件（AOA），不用网络共享。
- 新增 **USB 投屏(adb)**（`adb reverse` / localabstract）。
- 投屏发送：音频与视频分线程，写超时丢视频帧，减轻卡死和无声。
- USB 配件通道改为音视频分线程发送，并提供 input 供电脑控制包。
- 编码恢复真实宽高比（不再用正方形画布）。

## v1.0.10 (2026-09-24)

### 新增

- 选电脑 / 填 IP 配对时弹出「等待电脑确认」，直到电脑点允许或拒绝才关闭；可取消。

### 变更

- `node build.js release` 在写出 `release/screenkit{version}.apk` 后，拷到 ScreenKit 的 exe 输出 `apk/`，并 `slx ScreenKit` 编译一次。

## v1.0.9 (2026-09-23)

版本号随 ScreenKit 1.0.9 对齐（功能无变化）。

## v1.0.8 (2026-09-23)

首个随 ScreenKit 1.0.8 一起发布的版本。

### 新增

- 搜索 / 手选电脑、上次电脑直连、配对后文件与文本同步。
- 系统分享支持多文件（`SEND_MULTIPLE`）；「上传」可一次多选；一律写到电脑 `sendfile/` 根目录。
- App 在线时轮询收取电脑拖来的文件，写入绑定文件夹。
- 主界面传输列表：待传、进度、完成/失败；接收项带文件类型图标，点已完成项用系统「选择打开方式」打开。
- 文本同步：只读框显示最新一条，可选中复制。
- 标题栏三横菜单：**参数设置**（绑定接收文件夹）、**换电脑**。文本同步按钮在上传右侧，间距 10dp。

### 变更

- `build.js` 对齐 reader：`run/install/release/apk/devices`、增量编译、签名冲突卸载重装。

### 修复

- 局域网发现申请 Wi-Fi 组播锁、重复发送 UDP 探测；第一次扫描为空时再扫一次。
