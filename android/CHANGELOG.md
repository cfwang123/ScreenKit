# Changelog

（暂无）

## v1.0.9 (2026-09-23)

版本号随 ScreenKit 1.0.9 对齐（功能无变化）。

## v1.0.8 (2026-09-23)

首个随 ScreenKit 1.0.8 一起发布的版本。

### 新增

- 搜索 / 手选电脑、上次电脑直连、配对后文件与文本同步。
- 系统分享支持多文件（`SEND_MULTIPLE`）；「上传」可一次多选；一律写到电脑 `sendfile/` 根目录。
- App 在线时轮询收取电脑拖来的文件，写入绑定文件夹。
- 主界面传输列表：待传、进度、完成/失败；接收项带文件类型图标，点已完成项用系统「选择打开方式」打开。
- 文本同步：只读框显示最新一条，可选中复制。
- 标题栏三横菜单：**参数设置**（绑定接收文件夹）、**换电脑**。文本同步按钮在上传右侧，间距 10dp。

### 变更

- `build.js` 对齐 reader：`run/install/release/apk/devices`、增量编译、签名冲突卸载重装。

### 修复

- 局域网发现申请 Wi-Fi 组播锁、重复发送 UDP 探测；第一次扫描为空时再扫一次。
