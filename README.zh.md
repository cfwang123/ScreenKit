# ScreenKit

Windows 桌面工具（程序 `ScreenKit.exe`，中文界面标题「屏幕截图工具」）：截图识别、标注、条码/二维码、长截图、录屏/GIF、PDF 工作台、语音识别/合成、LLM 对话、翻译、人脸、本机 HTTP API，以及与安卓配套的局域网文件传输和投屏。

**当前版本：1.0.18** · [GitHub Releases](https://github.com/cfwang123/ScreenKit/releases/latest)

## 功能一览

### 截图与识别

| 模块 | 说明 |
|------|------|
| **截图识别** | 框选区域 → 按结果区 OCR / 条码 Tab 识别；多显示器 DXGI。模型可选 ONNX 包或 **Windows 系统 OCR**（未保存时的默认项；不加载模型，也不需要 OpenCV；语言单选，仅选该引擎时出现；边长上限两者都用）。ONNX 识别和条码仍会要求安装 OpenCV。长截图用 Bitmap 拼接，不需要 OpenCV。参数设置的识别页会写明当前引擎的特点。韩语/英语词间空格按画面词距补回；汉字之间不插空格。可选 LLM 叠字翻译。图区工具条是紧凑的 WPF 工具栏，放不下的项进入溢出菜单。**截图历史** 用缩略图列出保存目录（默认程序旁的 `screenshots/`；参数设置 → 截图可下拉改成 `D:/s/`，复制路径更短），可平移缩放预览，并在预览下方标注。有标注时完成、OCR 或用系统打开会另存并复制；没有标注时直接用原图，不生成新图。完成、OCR 或用系统打开后关闭历史窗口，在主界面显示这张图；OCR 会接着识别。复制和 Ctrl+C 只把当前图片放入剪贴板，不关闭窗口。图区右键可以粘贴（图片、复制的图片文件或图片路径）、打开截图历史、复制为图片、文件或路径、保存图片，用系统打开，在资源管理器中查看，重新标注，做文字识别或条码识别，以及清空。工具栏不再放截图历史、粘贴、复制图和保存。文件菜单仍有保存图片。 |
| **截图标注** | 微信式工具条：矩形 / 椭圆 / 箭头 / 画笔 / 文字，也可以不选工具。下次框选后直接用上次的工具。「截屏后用系统软件打开」；完成旁下拉「复制为图片 / 文件 / 路径」。 |
| **长截图** | 点选可滚动窗口 → 自动滚动，用 Bitmap 比对重叠行后拼接，按截图的复制方式写入剪贴板（图片 / 文件 / 路径）。不识别，不放到主界面，也不需要 OpenCV。 |
| **区域录屏** | 点选窗口或框选 → HUD → MP4 + 可选系统声/麦克风；可选叠加鼠标与点击高亮。编码：x264 / x265 / AV1（FFmpeg）、Windows Media Foundation H.264（MP4，不用下载）。 |
| **GIF 录屏** | 同选区流程 → 采集 24fps → 预览（帧率/缩放/调色板）→ 无声 GIF。 |
| **剪贴板** | 粘贴图片识别；「截图」菜单复制图片 / 文件 / 路径；菜单/托盘可切换截图完成时的复制方式。 |
| **文字叠加** | 松开才选一块，点空白取消，拖选不自动扩展；Ctrl+C 复制。 |
| **PDF 工作台** | **工具 → PDF 识别工作台**。打开 PDF → 分页识别 → 改字 → 导出可检索 PDF。 |

### 语音、对话、翻译、人脸

| 模块 | 说明 |
|------|------|
| **ASR / TTS** | 实时字幕可选离线或流式。未保存离线模型时用 Windows 系统识别器。Sherpa / SAPI / WinRT 离线合成及 Edge 在线自然语音。未保存引擎时，有 Windows 语音就用它，否则用 Edge 在线。语音合成的语言下拉每一项都显示名称，例如南非荷兰语 (af)。中文、英文、日文、韩文、越南语、粤语、法语、德语、西班牙语仍排在前面，其余按代码排列。SAPI 和 Windows 语音只列出有发音人的语言。Supertonic 使用固定噪声种子，同一段文字每次读音相同。 |
| **LLM对话** | 微信式气泡、清空、麦克风、朗读/自动朗读，可选网页与 `tmp/llm/` 工具。 |
| **LLM日志** | 主界面列出最近 1000 次 LLM 请求：模型、状态、输入 / 输出 / 合计 token、响应时间。选中一行查看请求和响应，JSON 里的中文按汉字显示。地址里的查询串不保存。 |
| **翻译** | 本地 Opus-MT ONNX 或已配置的 **LLM**；来回翻译最多 20 次，结果重复时提前停止；**工具 → 翻译小窗**（`Ctrl+Alt+T`）。 |
| **词典** | 主窗口里查汉语、英语、日语、韩语。详见 [词典](#词典)。菜单 **工具 → 词典**。`dict2.db` 不在发布包里。**帮助 → 安装功能**从固定的 `dict-db` 下载 `dict2.7z`，并删掉程序旁的旧 `dict.db`。 |
| **人脸识别** | InsightFace ONNX 检测/比对，可选关键点与性别年龄。模型在 `facemodels/`。 |
| **SAPI x86 助手** | 旁路 `x86host.exe`，调用仅 32 位可见的经典发音人。 |

### 传输、接口、安装

| 模块 | 说明 |
|------|------|
| **PC 文件传输** | 与 HTTP API 共用端口（默认 `1224`）+ UDP 发现 `17531`。主界面 **文件同步** Tab：上表平铺浏览程序旁 `sendfile/`（不进子目录），**列表 / 缩略图**切换、框选与 Shift/Ctrl 多选、**Ctrl+X/C** 剪切复制（剪切项半透明）、粘贴、删到回收站、拖到资源管理器。下方拖入在手机已连接时发到手机绑定文件夹；手机分享写到电脑 `sendfile/`。**安装到手机** 可检查并下载最新 APK，再显示局域网地址和二维码。**网页管理**（同一端口）：电脑 `/files`、手机 `/m`（紧凑列表、长按多选、上传/拍照/新建/文本传输），登录后上传/管理，下载只需 `/f/…`。配套 App：`android/`（`com.whj.screenkit`，桌面「传文件」「投屏」）。 |
| **HTTP API** | JSON 接口（默认端口 `1224`，勾选「允许局域网访问」后局域网也可连，否则只听 `127.0.0.1`）。主界面 Tab：调用日志 + 手动发请求。**工具 → web工具** 与托盘 **web工具** 相同。标题栏右侧的语言菜单加载 `/sk/L.js`。程序在请求时生成这个脚本，内容只有一次赋值 `L={...}`。每个值是已安装界面语言的数组，顺序与桌面语言列表相同，中文在前。浏览器可缓存 1 小时。重新启动后脚本地址变化，下次打开页面会重新获取。切换语言立即改当前页，不刷新。打开页面时用桌面程序的界面语言。第一项 **web工具主页**，下一项 **文件传输**（`/files`），再按分类列出全部工具，打开 `http://127.0.0.1:端口/#工具名`。地址或收藏不是当前卡片时忽略。进入工具后地址会带上这个 hash，并隐藏左侧分类栏，即本机工具页（聊天室在「交流」里，进入前填昵称和性别，可发图片和文件；历法、文本转换（简繁、日文注音、「其它」（变量名转换、Crontab解析、User-Agent解析、字符统计、token统计、合并空白、去掉空行）、XML、JSON 转义、SQL、HTML 转 JS 是其中的按钮；选过一次操作后，再改文字会直接出结果。复制旁边的「交换」把原文和结果对调）。文字分类里改输入或选项也会直接出结果。日文注音和正则仍要点按钮。「HTML 表格」卡片已去掉。「生成测试数据」按类型生成，一行一条。页面上会提示 Bogus 是否已安装。未安装时用内置数据，含中文网名、英文网名、MAC 地址和 UUID（原来的「MAC 地址」「UUID」卡片已去掉）。安装后先选 Bogus 的语言，再选该语言自己有数据的分类。日期、IP、MAC、UUID 每种语言都有。取色拖动色板或改 RGB 时直接写出 HEX、RGB、HSL、HSV、CMYK、YUV，没有转换按钮。YUV 是 BT.601 全范围，分量 0–255。图像里不再单列「颜色转换」和「调色板」。时间分类里秒表和倒计时合成「计时」：秒表、按秒倒计时，或选一个截止日期看剩余时间。工具页「图像」的画板铺满卡片，不显示标题和说明，也不滚动。矩形、椭圆、箭头、画笔直接画进图里。圈选抠起圈里的笔迹，拖动后画回图里，不再单独成为一个对象。Ctrl+V 粘贴的图片和文字可以拖动、改大小。页面变大时按新尺寸重建画布，内容不缩放；变小时画布保持原样。文字识别（在图像分类，已安装语言时打开即 Windows 系统 OCR）、语音合成（已有发音人时打开即 Windows 语音）、语音识别、8bit合成器（方波、脉冲、三角波、锯齿、风琴、铃、贝斯、笛子、噪声鼓，点琴键或用键盘演奏，琴键显示 3 个八度、宽度够一行不够三行，按住 Shift/Alt 升/降 8 度；可编排 4 通道循环，每路记住所选乐器。示例有进行曲、跳跃、水下、地牢、战斗、通关，各是一小节 FC `1米`，新单位默认「全部」，一次列出该类型所有单位；外币向中国银行查中间价，成功或失败都缓存 10 分钟，查询失败时用 2026-10-10 的牌价）、进制转换（转换到是下拉，默认「全部」，第一行是原来的进制，再列出 2、8、10、16 进制）、函数图像（输入 y=f(x) 或 z=f(x,y)，拖动平移、滚轮缩放；按住 Ctrl 只缩放 x 轴，按住 Shift 只缩放 y 轴；三维拖动转动视角，Shift 拖动平移）、颜色、颜色表（树形两支：web 颜色是全部 148 个 CSS 命名色，按红橙黄绿青蓝紫等 11 组；C# 颜色是本机 .NET 的 174 个名字，141 个命名色 + 33 个系统色，系统色色值随 Windows 主题。两支互不混，也没有「全部」；每个分组先出一行标题（红色、橙色……），下面才是该组色卡，每条是小色块 + 中文名 + 该平台的名字 + 十六进制，点一下复制十六进制）、哈希、计算器、正则（可批量测试，一行一条，通过为绿色、未通过为红色）、Unicode码表（左边分组，写出总字数以及每组字数和起止码；中间按宽度多列显示该组全部字符，格子够放下整个字，右边大字预览和编码；本机画不出的兼容字显示等价汉字，未分配码位标成空位）、ASCII码表（0x00–0x7F 分六组，每个分类都画在同一张经典 16 列码表上，带行列码表头，不属于本组的格子留空、整行都没有本组格子的行不画；控制字符显示 NUL、HT、DEL 这类缩写；点一下选中并复制；预览列出十进制、十六进制、八进制、二进制、Unicode 名称，以及 C、JavaScript、HTML、URL 转义）、GBK码表（按首字节分页，写出总字数以及每页字数和起止码，16 列，点一下复制，预览显示 GBK 字节）、摩斯码表（字母、数字、标点和信号，点一下复制点划并用 8bit 合成器试听，也可输入一段文字整段播放，字母之间空 3 点、词之间空 7 点）、图片转 ICO（方图按尺寸预览，带边框，可选 个）。文字识别可选引擎。选择或粘贴图片后立即开始识别，并显示预览，并显示与桌面相同的结果统计（耗时、置信度、引擎、图片宽高、行数、边长）。语音可选引擎、语言、性别与模型，可朗读或下载 WAV。发音人名称与桌面列表相同。打开页面即列出语音合成页已经加载的模型和发音人。选中模板后显示该接口的功能和参数说明。样式、脚本和图片缓存 1 小时。HTML | **安装功能** | 功能选择树打开时勾选已装项；增删显示绿/红数量与大小；点确认即安装或卸载。ONNX 语音模型与 Windows 语音各自一页。中文环境优先国内镜像。 |
| **字符画** | 菜单 **工具 → 字符画**：选择或拖入图片。单色结果是纯 ASCII。**全色字符画**用本程序自己的命令行窗口画全色：整块、上下半块、四象限，以及从左加宽的 1/8～7/8 块。默认的自动用四象限：四个象限里差得够开就拆成两色，接近一色的格子用空格铺背景色。按 1 仍是整块。滚轮朝光标缩放，拖动平移，命令行窗口变大变小会重画。 |
| **图片格式转换** | 菜单 **工具 → 图片格式转换**：批量转 JPG/PNG/PNG 调色板（2–256 色，按总色差最小分配，颜色不必取自原图）/BMP，可限制较短边（超过则等比缩小、不放大）、旋转/镜像；列表支持图片视图（小缩略图）与列表视图；选中后预览已应用质量与变换的效果，滚轮缩放、拖动平移、双击适应；输出到源文件旁 `output/`、指定目录，或替换源文件（永久删除 / 回收站）。可选：压缩后体积仍 ≥ 原图 N% 时用原图（默认 80%；有旋转或实际缩小时仍用新图）。不装 OpenCV 也能转 JPG/PNG/BMP/GIF/TIFF；已经装了时还能读 WebP 等，不会为此弹出安装。 |
| **视频转 GIF** | 菜单 **工具 → 视频转 GIF**：打开或拖入一个视频并预览播放，用起点和终点选取最多 60 秒，设置帧率、调色板（32/64/128/256，与 GIF 录屏相同）和较短边（默认 480），生成无声 GIF 并保存。需要 `ffmpeg64`。 |
| **快速复制** | 菜单 **工具 → 快速复制**：复制、剪切，或做成符号链接、硬链接（同一分区剪切优先改名）。同名可以覆盖、跳过或重命名。**注册菜单**给当前用户加上资源管理器级联菜单：快速剪切、快速复制、快速删除（回收站）、复制为符号链接、复制为硬链接、统计大小、复制路径、参数设置。符号链接指向选中的那一项。硬链接必须同一分区，文件夹会按目录给每个文件建硬链接。统计大小显示文件数、文件夹数和字节，不进入重解析点。参数设置打开本窗口并填入所选路径。剪切、复制或链接之后，文件夹空白处有快速粘贴和取消。已经注册过的菜单会在程序启动时重写。按着 Shift 复制相对路径。Windows 11 在「显示更多选项」里。一次选中大约超过 100 项时，这项静态菜单可能不出现。 |
| **视频批量转换** | 菜单 **工具 → 视频批量转换**：添加视频后用 FFmpeg 转到 MP4、MKV 或 WebM。默认 x265、CRF 40、较短边 480。声音默认保留，64 kbps、22050 Hz、单声道。MP4 / MKV 也可选 x264；WebM 仍用 VP9。输出到每个源文件旁的 `output/`、指定目录，或替换源文件（永久删除 / 回收站）。需要 `ffmpeg.exe`（`ffmpeg64/` 或 **帮助 → 安装功能**）。 |
| **二维码 / 条码** | **工具 → 二维码 / 条码生成**：QR、Data Matrix、Code 128/39、EAN、UPC。可选在图下显示一行原文（默认开），间隔为半行字高。编码 UTF-8、GBK 或 Hex 二进制（默认 UTF-8）。 |
| **批量重命名** | **工具 → 批量重命名**：源文件列表（添加/删除/上下移动，点列头按名称、修改或添加日期排序）；目标名用文本框可手改。Everything / FastCopy 风格（`%1`/`%2` 最短捕获、`#` / `###`）；改列表或规则时自动重算。 |

## 词典

查汉语、英语、日语、韩语。发布包不含词典文件。**帮助 → 安装功能** 会把它下载到程序旁边。

### 用法

- 语言按钮：全部、汉语、日语、韩语、英语。
- 每条结果显示语言、词头和释义，可以发音。词条里有读音、词性、义项、词组和例句。例句也可以发音。韩语词组和例句一样，原文后面有发音按钮，读韩语原文。
- **导出**写出这次搜索的全部词条，不受界面上的条数限制。每条都是详情的纯文本。txt 把它们接成一篇。csv 是表。html 和 md 是表格，列为单词、详情（详情列占满剩余宽度）。
- 在词条里双击、拖选或右键文字，会弹出匹配词头。悬停和选中都是深色字、浅蓝底。
- **参数设置 → 词典** 可改一次列出的条数（1～4000，默认 1000），以及数据库保持时间（分钟，默认 1，0 表示不关闭）。也可为每种语言选择引擎（自动 / ONNX / SAPI / Windows 语音 / Edge）、发音人和语速（0.5～2）。自动用该语言的 Windows 语音，没有则用 Edge。

### 数据来源

`dict2.db` 把四种词典放在同一个文件里。每个词只存一份，检索用文件里的压缩索引。ScreenKit 不生成这个文件。**帮助 → 安装功能**下载 `dict2.7z`，并删掉程序旁的旧 `dict.db`。程序旁已有 `dict2.db`（含指向别处的符号链接，按目标大小）时，词典显示为已安装。

- **汉语。** 汉字、词语、成语来自 [mapull/chinese-dictionary](https://github.com/mapull/chinese-dictionary)（拼音辞典）。许可为 MIT。上游说明里注明部分材料来源不明。
- **日语。** 词汇释义来自 [JMdict/EDICT](https://www.edrdg.org/wiki/index.php/JMdict-EDICT_Dictionary_Project)（EDRDG）。许可为 [CC BY-SA 4.0](https://www.edrdg.org/edrdg/license.html)。再分发须保留 EDRDG 署名，并遵守其更新条款。
- **韩语。** 国立国语院词典的衍生数据。许可为 CC BY-SA 2.0 KR。

## 运行环境

- Windows 10/11（x64）
- 终端用户：[.NET Framework 4.8](https://dotnet.microsoft.com/download/dotnet-framework/net48)
- 编译：Visual Studio / MSBuild（可编 `net48` WPF）
- 可选：NVIDIA 显卡 + 与 `onnxgpu64` 匹配的 CUDA；支持 DirectML 的 GPU（`onnxdml64`）
- 可选（x264 / x265 / AV1 与 GIF）：exe 旁 `ffmpeg64/` 放置 FFmpeg **4.4 shared**，或 **帮助 → 安装功能**（`dict-db` 的 `ffmpeg.7z`，约 33 MB）。系统 H.264 不用下载。

## 使用说明

### 截图、标注、识别

框选区域（热键或菜单）。结果区拆成 **OCR / 条码**。已选目标语且配置了 LLM 时，识别后可叠字翻译。标注工具在截图遮罩上；跨屏选区可在每一块相交的屏上画框、拖动或缩放（拖动热区在绿框外侧 10px）。「完成」下拉可复制为图片、文件或路径，并记住默认方式。框选结束后沿用上次的标注工具，也可以是不选任何工具。选择留在内存里，退出程序时才写入配置。屏幕画板仍从画笔开始，不改这条记录。**参数设置 → 截图** 可限制较短边：宽和高里较小的一边超过设定值时等比缩小，不超过则不放大。只影响保存目录与复制为文件，识别仍用原图。保存位置（`screenshot_dir`）默认填程序旁的 `screenshots/`，下拉可选 `D:/s/`，也可填其它目录。短目录让复制出来的路径更短。文件名（`screenshot_name`）可输入，也可下拉。默认是 `shot_yyyyMMdd_HHmmss_fff`。连续 `r` 是随机数字（`shot_yyyyMMdd_HHmmss_rrr`）。连续 `#` 是序号：`####` 存成 `0001.png`；`yyyyMMdd_###` 只在相同日期前缀的文件里取下一个序号。历史和启动时清理都用这个目录。

### 区域录屏 / GIF 录屏

1. **捕获 → 录屏**（或 GIF录屏）：单击窗口或拖拽框选。
2. **HUD**（画在选区外）：
   - 红框；拖动**红线外侧 5px**移动，或 **8 向手柄**缩放。**开始前**可自由改比例；**开始后**按 `record_lock_aspect`（默认锁定）。
   - 浮动**控制条**：左侧手柄拖动；可收起；显示当前声音来源。**选项**在开始前和录制中都在：开始前改全部参数，录制中改声音来源或关闭声音，马上生效。开始与暂停同一位置。限制在当前显示器内。
3. 停止后保存 MP4（资源管理器选中文件），或打开 GIF 预览（输出帧率 1–24、缩放、调色板）再保存无声 GIF。
4. **捕获 → 录屏选项**：编码（x264 / x265 / AV1 / 系统 H.264）、帧率。CRF 只在 x264/x265 时显示，AV1 CRF（0–63，默认 56）只在 AV1 时显示。还有音频、**限制较短边**（和截图一样，超过才等比缩小、不放大）、**录制鼠标** / **高亮鼠标点击**。AV1 需要 `ffmpeg64` 含 libsvtav1 / libaom-av1；找不到编码器会明确失败，不会改回 x264。系统 H.264 不用 FFmpeg，录制时把声音写成 AAC，采样率用 44.1kHz 或 48kHz，保存时不再另做一次合成。配置里如果还是 `mjpeg`，读入后改为系统 H.264。

GDI 抓屏不含指针：勾选 **录制鼠标** 叠加系统光标；**高亮鼠标点击** 在左键黄圈 / 右键蓝圈 / 中键绿圈处短暂散开。GIF 体积随分辨率与时长快速增大，请用预览缩放/帧率及最大尺寸限制。GIF 仍是最大宽高框。

### 文件同步（电脑 ↔ 安卓）

1. 电脑打开 **文件同步** Tab（参数设置 → web/接口里启用「PC 文件传输」，默认开）。
2. **安装到手机**：可检查并下载 GitHub 上的最新 APK，再显示局域网地址 `http://<电脑IP>:1224/apk` 和二维码（多网卡时默认用能连外网的地址）。手机与电脑同一局域网，用浏览器扫码安装。Windows 发布包不含 APK。
3. 首次连接：手机弹出等待窗（可取消）直到电脑允许配对。电脑弹窗始终置顶（主窗在托盘时仍能点到）。
4. 上表为电脑 `sendfile/` 接收目录（只看根目录、不进子目录；文件夹显示为一行）。**双击**文件用系统打开，双击文件夹用资源管理器打开。**右键**菜单作用于当前选中项（打开、剪切、复制、粘贴、推送、删除）；点在已选中的项上不会取消多选。工具栏可切换 **列表 / 缩略图**；支持框选、Shift 连选、Ctrl 多选；**Ctrl+X/C/V** 剪切/复制/粘贴（剪切后条目半透明），删除到回收站、拖到资源管理器。往列表上拖文件会导入接收目录。往**下方**拖放区拖入：仅在手机 App 已连接时发到手机绑定文件夹，无连接则不传。粘贴文件/图片进入接收目录；粘贴文本仍到右侧。手机分享/上传一律写到电脑 `sendfile/`。
5. 两端显示待传进度；电脑还有传输记录。文本同步是一个输入框，带 **发送**、**复制**、**清空**。手机自动连接只用局域网 IP，不用 USB 网段。
6. **网页管理**（同一 HTTP 端口）：**文件同步 → 网页管理** 显示局域网地址、二维码和登录密码。电脑版 `/files`，手机版 `/m`。`/index.html` 转到 `/files`。页面按浏览器语言显示中文或英文，并可用 **中文 / EN** 切换（记在本机浏览器）。登录后可上传、建目录、改名、删除等；可选 **保持登录**（约 30 天，重启本程序后仍然保持）。手机端：面包屑路径、紧凑列表（点击进入/下载，长按多选），底部 **上传 / 拍照 / 新建 / 文本**，多选后可下载、ZIP、复制链接、改名、删除。电脑页工具栏有 **文本传输**。对话框打开时显示电脑文件同步页的当前文本，可清空，或改完后 **推送到PC**（电脑复制到剪切板，并弹出「已复制文本：…」）。账户里可 **检查更新**（经电脑查询 GitHub 最新 APK）。**拍照** 会先按 **参数设置 → web/接口** 里的格式、JPG 质量、较短边在浏览器里压缩再上传。浏览器压不了时，电脑仍按同一组参数处理。更新电脑程序后请重新打开网页再拍。正确的 `/f/相对路径` 即可下载，无需登录。交互参考：`ScreenKit/SendFile/web/m-prototype.html`。

安卓端说明：[android/README.md](android/README.md)。

### 投屏（电脑 ↔ 安卓 / 电脑 ↔ 电脑）

1. 电脑保持本程序运行（默认启动即接收；参数设置 → web/接口可关）。**托盘 → 工具 → 投屏**打开主窗口并切到投屏页。同一 Wi‑Fi，不要访客隔离。启动本程序会结束其它目录的旧 ScreenKit。WiFi/ADB 画面走与传文件相同的 HTTP 口（`/cast`），扫描走 UDP 17531。
2. 手机 **传文件/投屏** → **投屏**。页面会带上已保存的电脑 IP，确认后点 **开始投屏**，允许截屏。要换电脑用 **已保存的电脑** 或 **搜索局域网**。投屏中才出现 **停止投屏**。数据线投屏在页面下方单独一项。画面走 HTTP `/cast`（默认 1224）。局域网网卡上的文件传输监听也会完成这次 WebSocket 握手。电脑未开、握手失败、中途断开或未授权截屏时弹出 **投屏失败** 对话框。约 90 秒没有配件则改走 USB 网络共享。**USB 调试投屏** 走 `adb reverse`，需要 USB 调试。调试转发：`adb shell am start -n com.whj.screenkit/.CastActivity --ez scst_adb_probe true`（只看 127.0.0.1:1224 是否通）。WiFi 握手：`--es scst_ip <电脑局域网IP> --ez scst_wifi_probe true`。纯 USB 测试画面：`scst_usb_pat`。
3. 电脑在主屏幕中心弹出无边框画面窗并提到最前；**Tab** 信息默认不显示（按 Tab 才显示类型、分辨率、帧率等）。关闭画面即断开。画质档可即时改。横屏会按同一画质短边重编码，不把竖屏画面裁小。手机停止投屏时电脑窗口立刻关闭（`GET /api/cast/stop`）。
4. 电脑互投：接收端开着本程序（默认即接收）。发送端打开主界面 **投屏**，点左侧已保存的电脑填入 IP（或搜索局域网，含本机），设最大宽高后点 **开始投屏**，先单击窗口或拖拽框选区域，再开始发送。

### 字符画

**工具 → 字符画**：选择或拖入一张图片。窗口里是纯 ASCII（可改列数、反色）。**全色字符画**会再启动本程序并带上 `--charart`，在命令行窗口里用 24 位色画同一张图。每个格子可以是整块、上下半块、四象限，或从左往右占 1/8 到 7/8 宽的块。默认的自动用四象限：四个象限里差得够开就拆成两色，接近一色的格子用空格铺背景色。滚轮朝光标缩放，拖动平移，双击适应，窗口变大变小按当前缩放重画。按键：1 整块、2 半块、4 四分块、8 八分宽、0 自动、F 适应、Q 退出。

### 图片格式转换

**工具 → 图片格式转换**：拖入文件、文件夹或图片；目标 JPG / PNG / PNG 调色板（2–256 色，按总色差最小分配，颜色不必取自原图）/ BMP；可选限制较短边（宽高里较小的一边超过则等比缩小，不放大）；选中项可旋转 90/180/270° 或镜像。**图片**视图显示小缩略图（可切回 **列表**）。右侧预览已应用质量与变换后的效果，滚轮缩放、拖动平移、双击适应。一键转换输出到每个源文件旁的 `output/`、指定目录，或替换源文件（永久删除 / 回收站；转换前会确认）。不装 OpenCV 也能转常见格式（JPG、PNG、BMP、GIF、TIFF）。程序旁已经有 OpenCvSharpExtern 时，还能读 WebP 等更多格式，不会为此弹出安装。

### 视频批量转换

**工具 → 视频批量转换**：拖入文件或文件夹，或添加视频。目标 MP4 / MKV / WebM；编码默认 x265（也可 x264；WebM 仍用 VP9）；CRF（x264 / x265 为 0–51，WebM 为 0–63，默认 40）；较短边默认 480（超过则等比缩小，宽高取偶数，不放大）；声音默认保留，码率 64 kbps、采样率 22050 Hz、单声道（取消单声道则保留源声道数）。一键转换输出到每个源文件旁的 `output/`、指定目录，或替换源文件（永久删除 / 回收站；转换前会确认）。编码使用程序旁 `ffmpeg64/` 里的 `ffmpeg.exe`，也可从 **帮助 → 安装功能** 安装。

### 视频转 GIF

**工具 → 视频转 GIF**：打开或拖入一个视频，在窗口里播放并拖动进度。起点和终点用秒填写，也可以把当前画面设为起点或终点。区间最长 60 秒。帧率默认 8（1–30，不会高于源视频）。调色板与 GIF 录屏相同，可选 32、64、128、256 色，默认 128。较短边默认 480，超过才等比缩小。生成的 GIF 没有声音。需要 **帮助 → 安装功能** 里的 FFmpeg（`ffmpeg64`）。

### 界面语言

菜单栏上的 **界面语言**，或 **参数设置 → 常规**。每种语言是程序目录 `lang/` 下的一个 toml（已有中文、英文、日文、韩文，以及其它语言：德文、西班牙文、法文、葡萄牙文、俄文，也可自己加）。启动时读入全部文件，列表按中文、英文、日文、韩文，以及其它语言排序。`config.toml` 的 `ui_lang` 是这个文件名。缺的句子回退中文。已覆盖菜单、参数设置、OCR 工具栏模型/语言显示名（`ocr-display.json` 的 `name` / `nameEn`）、翻译、人脸、翻译小窗、词典窗口等。

加一条或改一条文案只要一行命令，可以只写一个语言，也可以一次写进全部语言：

```
rem 只改中文
scripts\langtext.cmd set app.demo.title "演示标题" -l zh
rem 全部语言写同一条文本
scripts\langtext.cmd set app.demo.title "Demo title" -l all
rem 逐语言给不同文本
scripts\langtext.cmd set app.demo.title -l all --each zh=演示标题 --each en=Demo title
rem 删掉一个键（del / rm / remove，或 set 键 --delete）
scripts\langtext.cmd del app.demo.title -l all
rem 查看、体检、批量补齐
scripts\langtext.cmd get app.demo.title -l zh,en
scripts\langtext.cmd missing --base zh
scripts\langtext.cmd fill --from zh -l all
scripts\langtext.cmd -h
```

新键追加到 `[text]` 末尾，或用 `--after <键>` 插到某个键之后。`del 键…` 删除一条或多条键（`rm`、`remove`、`delete` 是同一个命令，写成 `set 键 --delete` 也一样）；只删部分语言时会提示哪些语言还留着这个键。每个文件保留自己原有的换行风格（CRLF / LF）和无 BOM，未涉及的行不动。文本里的换行写 `\n`。只改 `[text]` 段里的键，`name`（语言显示名）不碰。`--dry-run` 只预览不写盘。`--sync` 顺带把改过的文件覆盖到 `ScreenKit\bin` 下已有的 `lang/` 副本，正在跑的 exe 不用重新编译就能读到。

### 检查更新

**帮助 → 检查更新**（启动时也会按参数里的间隔检查）。有新版本时弹出窗口，列出当前版本之后直到最新版的每个版本。选中一行查看该版本的更新说明。**中文 / English** 切换说明语言。**更新**下载并安装最新包。**忽略**关闭窗口。

| **SharpSevenZip / 7za** | 解压词典 `dict2.7z` | ~1.8 MB + ~0.4 MB |
| **SQLite** | `e_sqlite3.dll`。打开 `dict2.db` | ~1.7 MB |
| **ffmpeg64** | x264 / x265 / AV1 与 GIF | 7z 约 33 MB / 解压约 117 MB |

安装窗口和参数设置里的 HTTP 代理有三项：跟随系统、手动地址、不用。用了代理时先下 GitHub / Hugging Face，失败再试国内镜像；不用代理时顺序相反。国内镜像和 `.cn` 仍然直连。

**Edge 在线**引擎无需安装模型或填写 API Key，可使用 300 多个 Microsoft 自然语音（含韩语）。必须联网，发音人目录和合成文本会发送到 Microsoft Edge「朗读」服务；不是收费的 Azure Speech API，可用性可能变化。程序沿用 HTTP 代理：跟随系统、手动地址，或不用。

可选环境变量（勿把本机密钥/绝对路径写进对外文档）：

| 变量 | 含义 |
|------|------|
| `WPF_OCR_CUDA_LIB` | 完整 CUDA / onnxgpu64 DLL 目录 |
| `WPF_OCR_FFMPEG_LIB` | FFmpeg 4.4 shared DLL 目录 |

## HTTP API（简述）

启用后监听 `http_port`（默认 `1224`）。`http_lan = true`（默认）时本机与局域网都可访问；`false` 时只听 `127.0.0.1`。没有 `http_lan` 时用这个默认值。已停用的配置键不读。监听用普通 TCP 套接字，和 websocket-sharp 一样，开局域网不需要管理员，也不需要 HTTP.sys 的 URL 预留。文件传输、网页管理和 Wi-Fi 投屏共用此端口，需要局域网时保持勾选。无鉴权，勿在未受控网络上暴露。接口失败也返回 HTTP 200，错误在 JSON 的 `code` 和 `data`。

**PC 文件传输** 与此 HTTP 端口共用（`1224`）并另有 UDP `17531`（需配对）：[HTTP接口文档.md](HTTP接口文档.md) · [android/README.md](android/README.md)。

- `GET  /api?lang=` · `/api/status` — `/api` 列出仍开启的接口，含方法和 HTTP 页里的参数说明。`lang` 省略时用程序当前语言。
- `GET/POST /api/toast` — 底部 Toast（`text`，可选 `ms`）。命令行：`ScreenKit --toast "文字" [--ms 1900]`。HTTP 接口页的模板下拉里也有这两项。
- `GET/POST /api/zhconv` — 简繁（`text`，`to=trad|simp`）。GET 查询串按 UTF-8 解码。命令行：`ScreenKit --zhconv "文字" [--trad|--simp]`
- `GET/POST /api/pinyin` — 中文转拼音（`text`，`mode=py|init`）。不带 text 时 `data.installed` 表示是否已装 `NPinyin.dll`。有原文但没装库返回 803。不带声调。读音来自 `pinyin.toml`，`pinyin.user.toml` 的同名词条盖住它。命令行：`ScreenKit --pinyin "重庆" [--init]`
- `GET/POST /api/calendar` — 历法（`date`，`cal=lunar` 等）。命令行：`ScreenKit --calendar 2024-02-10 --cal lunar`
- `GET/POST /api/jpyomi` — 日文注音（`text`，可选 `mono`）。命令行：`ScreenKit --jpyomi "日文" [--mono]`
- `GET/POST /api/cast/stop` — 立刻关闭投屏画面窗
- WebSocket `/cast` — 投屏媒体（与 HTTP API 同端口）
- WebSocket `/chat` — 工具页聊天室。进入前填昵称和性别，浏览器记住上次的昵称和性别。同一台正在运行的 ScreenKit 上的人互相发文字、图片和文件。图片和文件写到程序目录 `tmp/chat-` 加编号（单个 8 MB），下次启动时删除。文字只留在内存里。每 5 秒一次心跳，失败就断开。可以指定发给某一个人，包括自己。私密消息只有双方能看到；发给自己时只有自己能看到。直传把文件经服务器交给对方，对方点接收后才开始下载
- `POST /api/ocr` — `box` 为原图像素。`ocr.engine=winocr` 让这一次走 Windows 系统 OCR
- `POST /api/qr` — 仅条码/二维码（`/api/barcode`）
- `GET  /api/ocr/get_options`
- `GET  /api/asr/models` · `POST /api/asr`
- `GET  /api/tts/engines` · `GET /api/tts/models?engine=` · `POST /api/tts` — Sherpa、SAPI、Windows（`engine=winrt`）、Edge（`engine=edge`）。桌面程序打开时，这就是语音合成页当前的列表，打开即返回。否则全量列表会缓存，`refresh=1` 重新扫描。`GET /api/tts/devices` 列出播放设备。`POST /api/tts/speak` 用同样的合成参数直接播放，`play=queue` 排队，`play=now` 立即打断，可指定一个或多个设备。
- `POST /api/itn`
- `POST /api/translate` — LLM 批量（`items[]`）
- `GET  /api/face/models` · `POST /api/face`

完整字段：[HTTP接口文档.md](HTTP接口文档.md) · [HTTP-API.md](HTTP-API.md)（English）。

## x86host（仅 32 位 SAPI）

部分经典 **SAPI** 发音人只在 32 位进程中可见。请将 **`x86host.exe`** 与 `ScreenKit.exe` 放在同目录（工程 `x86host/`；Release 编 ScreenKit 时会自动编译并拷贝）。

| 项 | 说明 |
|----|------|
| 作用 | HTTP 助手：列 SAPI 发音人 + 合成 WAV；**无 GUI** |
| 启动 | x64 主程序按需拉起，或手动运行 |
| 监听 | 仅 `127.0.0.1`，默认端口 **17886** |
| 空闲 | **60 秒**无请求自动退出（`--idle-ms` 可改） |
| API | `GET /api/sapi/status` · `GET /api/sapi/voices` · `POST /api/sapi/synth` · `POST /api/sapi/shutdown` |

```text
dotnet build x86host/x86host.csproj -c Release
x86host.exe --port 17886 --idle-ms 60000
x86host.exe --list-sapi
```

界面中引擎选 **SAPI**：列表含本机音与 **x86 独有**音（显示名带 `· x86`）。

**源码目录不包含模型与大型运行库。** 请放到可执行文件旁，或在程序内「安装功能」下载：

ScreenKit/bin/Release/net48/
├── ScreenKit.exe

**Release** 编译不会复制这些目录。每个 OCR 模型包需包含 ONNX、`configs.txt` 以及字典/keys。可选 `pack.json`（`name` / `nameEn` / `variants`）提供英文显示名；内置默认在程序旁 `ocr-display.json`。模型列表中的 **Windows 系统 OCR** 不使用这些目录，语言来自本机已安装的 OCR 语言包。

```bash
cd ScreenKit
dotnet build -c Release
./ScreenKit/bin/Release/net48/ScreenKit.exe
```

### 精简发布包（`bin\Release\ScreenKit\`）

- **包含**：`ScreenKit.exe`、**`x86host.exe`**、托管依赖、**`wetext/`**（ITN）、Assets、许可证、`web/`、`pinyin.toml`、`pinyin.user.toml`。工具页只有合成后的 `tools.js`，没有 `web/tools` 里的各工具脚本。
- **不含**：安卓 APK、OCR/ASR/TTS/人脸模型、ORT、OpenCV / Skia / PDFium、Sherpa natives、`ffmpeg64`、`dict2.db`、`ZXing.dll`、`SharpCompress.dll`、`SharpSevenZip.dll`、`7za.dll`、`e_sqlite3.dll`、`Bogus.dll`、`NPinyin.dll`。词典库用 **帮助 → 安装功能** 下载，或自行放在程序旁边。数据从哪来见 [词典](#词典)。条码、解压和词典在使用时若缺库，会提示安装。
- 用户通过 **安装功能** 按需下载。本地 Opus-MT 需自行将 ONNX 放到 `translatemodels/`。

本机开发且已有模型时，请继续用 **`bin\Release\net48\`**。

### 发布压缩包

```bash
node scripts/publish-release.mjs
```
