# ScreenKit

Windows 桌面工具（`ScreenKit.exe`，界面标题「屏幕截图工具」）：截图识别、标注、录屏、语音、翻译、词典、人脸，以及和安卓配套的传文件、投屏。本机还有 HTTP 接口和浏览器工具页。

**当前版本：1.0.21** · [发布包](https://github.com/cfwang123/ScreenKit/releases/latest) · [更新日志](CHANGELOG.md) · [English](README.md)

接口、编译和逐步操作仍保留在 [完整说明](docs/archive/README.zh.md)。

![主界面](docs/1%20screenshot.png)

关掉主窗口会进托盘，不会退出。托盘单击与主窗口热键相同：已在前面就隐藏，否则显示到最前。右键可语音输入、打开翻译小窗、从剪贴板识别、切换截图复制方式，或退出。

## 截图与识别

- **截图识别**：热键或菜单框选区域，结果区分为 OCR 和条码。未另选模型时用 Windows 系统 OCR，不加载 ONNX，也不需要 OpenCV。装了 ONNX 模型后可换引擎；韩语、英语会按画面词距补回空格。已选目标语言且配置了 LLM 时，识别后可叠字翻译。多显示器时，选区落在哪几块屏上，就在那几块上画框。
- **截图标注**：矩形、椭圆、箭头、画笔、文字，也可以不选工具。下次框选沿用上次的工具。完成时可复制为图片、文件或路径，并记住这次的选择。标注条上按 `P` 只切换复制方式，不结束本次截图。
- **长截图**：点选可滚动窗口，自动滚动后拼接，按当前复制方式写入剪贴板。不识别，也不放到主界面，不需要 OpenCV。
- **截图历史**：用缩略图列出保存目录里的图，可平移、缩放和标注。有标注时，完成、OCR 或用系统打开会另存；没有标注则直接用原图。复制只把图放进剪贴板，不关窗口。
- **保存**：有 D 盘时目录默认是 `D:/s/`，否则是程序旁的 `screenshots/`。文件名默认 `dd_##`（日和两位序号），也可改成带时间、纯序号或随机数字。可限制较短边：超过才等比缩小，且只影响保存和「复制为文件」，识别仍用原图。保存位置和复制出来的截图路径用 `/`。改用 `/` 可避免转义，减少 token 使用和 LLM 出错。
- **文字叠加**：松开后才定一块区域，拖选不自动扩展。Ctrl+C 复制，点空白取消。
- **剪贴板**：可粘贴图片再识别。图区右键可粘贴、打开历史、复制为图片 / 文件 / 路径、保存、用系统打开、重新标注、做文字或条码识别。菜单、托盘或 `Ctrl+Alt+P` 切换复制方式时，会立刻用新方式再写一次上次截图。
- **PDF 工作台**：**工具 → PDF 识别工作台**。打开 PDF，分页识别，改字后导出可检索 PDF。

## 录屏

**捕获 → 录屏** 或 **GIF 录屏**：单击窗口，或拖拽框选。

- 红框画在选区外。开始前可改大小和比例；开始后默认锁定比例。控制条可拖动、收起。开始前能改全部参数；录制中可改声音来源或关掉声音，马上生效。
- **区域录屏**写成 MP4，可录系统声、麦克风，或两者，也可叠加鼠标和点击高亮（左键黄圈、右键蓝圈、中键绿圈）。默认用系统 H.264，不用 FFmpeg；也可选 x264、x265、AV1。AV1 需要已安装的 FFmpeg。停止后在资源管理器里选中该文件。
- **GIF 录屏**用同一套选区采集，再打开预览。可调输出帧率、缩放和调色板（32 / 64 / 128 / 256 色），保存无声 GIF。采集不用 FFmpeg。画面大、时间长时文件会很快变大，宜先缩小或降低帧率。
- **捕获 → 录屏选项**里还有帧率，以及和截图一样的「限制较短边」。

## 语音、翻译、词典、人脸

- **语音识别**：实时字幕可选离线或流式。未保存离线模型时用 Windows 系统识别。缺少的语言可在 **帮助 → 安装功能 → Windows OCR/语音** 里安装。
- **语音合成**：Windows 语音、SAPI、离线语音、联网的 Edge 自然语音，以及本机 Chrome 里的 Google 语音。发不出声时桌面弹出错误，HTTP 返回错误，不改用别的语音。没有已保存的引擎时，优先用本机 Windows 语音，否则用 Edge。Edge 不另装模型，需联网。Chrome 需要本机 `chrome.exe`（在参数设置 → 常规里指定路径，或点「检测路径」搜索常见安装位置）。对应语言的离线语音包若还没装，朗读时会临时安装，并显示可中止的进度窗。HTTP 接口不代为安装，需要事先在安装功能里装好，否则返回 927。朗读时不显示窗口，声音走系统当前的默认输出设备，空闲默认 60 秒后退出（可改，0 为不自动关）。朗读和翻译共用这一个隐藏 Chrome，请求在这个窗口里排队。这个进程还在时，状态栏显示「Chrome 子进程运行中」，并带上还活着的子进程数。不能导出音频。网页工具里的播放也走这个默认设备。仅 32 位的经典发音人经旁边的 `x86host.exe` 调用。语言列表里，中文、英文、日文、韩文等常用语言排在前面。
- **语音输入**：热键开始，再按结束，把识别结果送进当前输入位置。
- **对话**：接已配置的 LLM。微信式气泡，可清空、用麦克风输入、朗读或自动朗读，也可打开网页和本地工具。
- **LLM 日志**：主界面列出最近约 1000 次请求，可看模型、状态、token、耗时，以及请求和响应。地址里的查询串不保存。
- **翻译**：本地 Opus-MT（中英）、已配置的 LLM，或本机 Chrome 的翻译。Chrome 用参数设置里的 `chrome.exe`，和朗读共用同一个隐藏进程，语言包由 Chrome 按需下载。来回翻译最多 20 次，结果重复时提前停下。**工具 → 翻译小窗**里可以选择本地 ONNX、Chrome 或已配置的 LLM（与主界面同一项，不另选模型），原文和译文都能发音。
- **人脸**：InsightFace 检测和比对，可选关键点、性别年龄。模型在安装功能里下载。
- **中文转拼音**：不带声调，或每个字一个大写首字母。常见多音词在程序旁的 `pinyin.toml`（如「重庆」「银行」）。`pinyin.user.toml` 里的同名词条盖住它；读音留空就改回默认读音。升级会换系统词表，不会动用户词表。网页卡片和 `GET/POST /api/pinyin` 只传原文，同时返回 `pinyin`（全拼）和 `py`（首字母）。
- **韩语输入**：工具菜单或默认 `Ctrl+Alt+K` 打开后接管键盘，和 Windows 韩语输入法一样用两套式在光标处组字，没有候选条。元音各自独立，不会并成双元音。退格拆掉最后一笔。空格、回车和标点先留下已经组好的字，再输入这个键。单独按 Shift，或按右 Alt，在韩文和英文之间切换。Shift 加辅音仍是双辅音，元音不加双。打开后任务栏另有一个图标，绿底是韩文、灰底是英文，左键切换，右键可关闭或打开参数设置。在本程序窗口里按键仍交给系统。再按一次快捷键把键盘交还系统。
- **简繁转换**：上面简体、下面繁体。走系统接口，繁体接近台湾用字，不做词级替换。
- **日文注音**：把日文句子转成读音，可按词或逐字。需要本机已安装日语。
- **历法**：公历换农历（干支、闰月），以及日本、民国、希伯来、伊斯兰、波斯等历法。

### 词典

主窗口或 **工具 → 词典**。查汉语、英语、日语、韩语。发布包不含词典文件，在 **帮助 → 安装功能** 下载到程序旁边。

- 语言按钮：全部、汉语、日语、韩语、英语。
- 每条显示语言、词头和释义，可以发音。展开后有读音、词性、义项、词组和例句，例句也可以发音。
- **导出**写出这次搜索的全部词条，不限界面上的条数。txt 接成一篇，csv 是表，html 和 md 是表格。
- 在词条里双击、拖选或右键，会弹出匹配的词头。
- **参数设置 → 词典**可改一次列出的条数、数据库保持时间，以及每种语言的引擎、发音人和语速。引擎选自动时，用该语言的 Windows 语音，没有则用 Edge。
- 词典热键默认是空的。设上之后：不在主窗口时唤出并切到词典（剪贴板像一个单词才搜索）；已经是主窗口时隐藏。
- 网页是单独一页 `/dict`。工具页左下角「词典」、菜单和托盘的 **web工具** 都在新窗口打开，不嵌进工具卡片。查词、四种语言、发音、导出和划词与上面相同。划词里的「翻译」打开工具页的翻译。

## 文件与投屏

### 文件同步

电脑打开 **文件同步**。手机与电脑在同一局域网。发布包不含 APK，这一页的 **安装到手机** 可检查并下载，再用二维码安装。首次连接时，手机等到电脑允许配对；电脑的询问窗会保持在最前。

- 上表是程序旁的 `sendfile/`，只看这一层，不进入子目录。双击文件用系统打开，双击文件夹用资源管理器打开。可列表或缩略图、框选、多选，Ctrl+X/C/V 剪切复制粘贴，删除进回收站。剪切后的项会变淡。
- 把文件拖进列表，是放进接收目录。拖到下方区域，只在手机已连接时发到手机绑定的文件夹。手机分享或上传，都写到电脑的 `sendfile/`。文本有发送、复制、清空。
- **网页管理**用同一端口。电脑打开 `/files`，手机打开 `/m`。登录后可上传、建目录、改名、删除；下载链接不用登录。手机页可上传、拍照、新建和传文本。

### 投屏

电脑保持本程序运行就会接收，可在参数里关掉。**托盘 → 工具 → 投屏**打开主窗口并切到投屏页。同一 Wi-Fi，不要开访客隔离。

- **电脑投到电脑**：发送端在左侧点已保存的电脑，或搜索局域网（含本机），也可手填 IP。默认把画面限制在 1000×1000 以内，只缩小不放大。点开始后先框选区域，再选声音（扬声器、麦克风或两者），然后才发送。红框和操作条不进入对方画面。暂停只停画面和声音，连接还在。
- **手机投到电脑**：手机应用里选已保存的电脑或搜索局域网，允许截屏后开始。数据线可走 USB 调试，或 USB 配件。失败、断开或未授权时，手机会提示投屏失败。
- 接收窗默认在主屏幕中心打开，不置顶。画面可适应窗口或铺满。关闭窗口即断开。按 Tab 才显示分辨率、帧率等信息。投屏中可改画质和声音来源。

## 工具

- **图片格式转换**：批量转 JPG、PNG、PNG 调色板、BMP，也可读 GIF、TIFF。可限制较短边、旋转和镜像。列表可看缩略图，右侧预览变换后的效果。输出到源文件旁的 `output/`、指定目录，或替换源文件（删除前会确认）。已经装了 OpenCV 时，还能多读 WebP 等格式。
- **视频批量转换**：转到 MP4、MKV 或 WebM。默认可压短边、保留声音。输出位置与图片转换相同。需要 FFmpeg。
- **视频转 GIF**：打开或拖入一个视频并播放，拖动经过窗口时在预览区提示松开。用起点和终点选取，最长约 60 秒。可调帧率、调色板和较短边，生成无声 GIF。需要 FFmpeg。
- **字符画**：纯 ASCII，列数默认 250，预览字号默认 6。不勾选反色时越暗的地方字符越密，阈值把不够暗的地方留空。预览字号用滑块调整。勾选线条后，按画面里的边缘方向用 `-`、`|`、`/`、`\` 和 `+` 来画。阈值为 0 时很淡的边也会留下。全色字符画在命令行窗口里画，可缩放、平移。
- **像素画**：先选宽和高（1–128，也可直接用 8、16、32、64）。在大格子上涂色，快速划过时经过的格子都会涂上。旁边按真实像素大小预览。可复制或保存 PNG。
- **字符点阵提取**：选定字体和字号，把每个字画成点阵。可逐行或逐列、调高低位和阴阳码，导出 C 数组、十六进制或点阵文本。
- **二维码 / 条码生成**：QR、Data Matrix、Code 128/39、EAN、UPC。可选在图下写一行原文。编码可用 UTF-8、GBK 或十六进制。
- **批量重命名**：添加文件后手改目标名，或用 `%1`、`#` 这类规则。改列表或规则时自动重算，可按名称或日期排序。
- **快速复制**：复制、剪切、永久删除、删到回收站，或做成符号链接、硬链接。同名可覆盖、跳过或重命名。**注册菜单**后，资源管理器里有对应的级联菜单；剪切或复制之后，文件夹空白处可快速粘贴。
- **校验哈希**：MD5、SHA-1、SHA-256，可粘贴期望值比对。
- **文本小工具**：Base64、URL、UTF-8/GBK 十六进制、Unicode 转义、大小写、空白、字数，以及 JSON 美化。
- **MD 阅读器**：打开或拖入 Markdown 文件，转成 HTML 后用 Windows 10 自带的 IE11 内核（WebBrowser）显示。图片按文件所在目录加载。网页链接用系统浏览器打开。工具页「文字」里的同名卡片也是拖入预览，转换规则相同。`POST /api/md` 传 `text` 或文件的 `base64`，可选 `title`，返回 `data.html`。
- **密码生成器**：打开就生成一批。可调长度、字符种类，以及是否排除易混字符。另有单词译音和变体：把一句密码交已配置的 LLM，译成其它语言再用拼音或罗马字拼出来。
- **网络工具**：工具菜单里的「网络工具」子菜单有三项：网络工具、HTTP 请求调试、网络端口占用。其中“网络工具”打开一个窗口，用窗口里的按钮完成这些操作。包括 Ping、DNS、ARP、WHOIS、路由跟踪，以及 Ping、代理、HTTP 测速、IP 城市、MAC 厂家、USB ID 查询、Windows 系统定位和“IP 扫描”。DNS 会逐步显示所用服务器、A/AAAA 地址、别名、耗时和 PTR 反查；DNS 记录再查询 CNAME、MX、NS、TXT 和 SOA。端口测试检查指定 TCP 端口，未写端口时检查常用端口。端口扫描是单独的标签页，填入 IP 和端口范围（如 `1-1024` 或 `80,443,8000-8100`）后开始，也可点「常用端口」。超时可在 100 到 5000 毫秒之间调整。进度条显示已扫比例。列表只列出开放端口；类型优先根据对方主动发来的第一行标识判断，没有标识时按端口号，认不出的记为 TCP。本机网络列出活动网卡的地址、掩码、网关、DNS、速率和 IPv4 路由。网络唤醒按 MAC 地址发送魔术包。ARP 可将本地主机/IP 解析为 MAC，也可从本机接口和当前 ARP 缓存按 MAC 反查 IP。IP 扫描是单独的标签页，探测活动的本地 IPv4 网络，用进度条显示已探测地址，探测一结束就列出 IP 和 MAC，主机名先是横线，每解析出一个名称就改那一行。没有 PTR 记录时再尝试 NetBIOS 名称。右键一行可复制主机名、IP 或 MAC。选中一台后可把它的 IP 带到端口扫描。网络发现使用 Windows 的网络文件夹和计算机浏览器，列出其它电脑的名称、说明、IP 和 MAC；需要专用网络并打开网络发现。IP 城市用输入框里的地址，留空则查本机出口；同一查询也是 `GET/POST /api/ipcity`。MAC 厂家查询 IEEE 登记的厂商，同一查询是 `GET/POST /api/mac`；本地管理地址没有厂家。USB ID 查询用 VID 或 VID:PID 查 Linux usb.ids，返回厂家、产品、型号和该产品下的接口。同一查询是 `GET/POST /api/usb`，名单缓存在程序目录 tmp，超过 7 天再下载。地图用浏览器打开。
- **网络端口占用**：位于「网络工具」。列出正在使用的 TCP、UDP 端口，监听的排在前面。选中可看进程和路径，并打开所在位置。
- **系统信息**：每个 Tab 第一次进入时才在后台查询，刷新只重查当前页。除系统、USB、串口、打印机、声音和字体外，还列出显示器、摄像头、蓝牙、网络适配器、输入设备、物理磁盘、电池、PCI/系统设备和异常设备；可查看驱动、标识、状态，以及系统能提供的分辨率/DPI、磁盘健康和电池容量等信息。系统页还有每条内存的插槽、容量、频率，以及主板厂商和型号。声音设备默认只显示活动项，显示全部时活动项仍靠前。查询只读，不打开或控制设备；权限不足时通过 `start` 调用本程序的管理员命令行，取消或失败会显示原因，可点刷新重试。
- **系统工具**：工具菜单和托盘的「系统」里。只读列出进程（名称、PID、内存、路径、命令行）、环境变量（用户和系统分开，值里的分号在详情中换行）、启动项（Run、启动文件夹、登录或开机的计划任务）、已安装程序（名称、版本、发行者、日期、卸载命令）、服务（名称、状态、启动类型、路径）、已安装补丁，以及当前用户的商店和 UWP 应用。文件占用可选择或拖入文件、文件夹，查出正在占用它的进程。文件关联输入扩展名后显示默认程序。服务只列出，不启动也不停止。
- **性能监控**：工具菜单和托盘的「系统」里。半透明无边框小窗，可拖动，记住位置。显示 CPU、GPU、内存占用，网络上传下载，磁盘读写，以及能读到的 CPU/GPU 温度和功率。读不到的项显示横线。右键可单独开关每一项，也可置顶或关闭。
- **文件分析**：工具菜单和托盘的「文件」里。选择或拖入一个文件，按文件头判断类型并和扩展名对照，可看 exe/dll 的产品名、版本和公司。图片显示宽高、拍摄时间和相机制造商，GPS 只在本窗口显示。有 ffmpeg 时读取时长、分辨率、编码和码率，没有则只显示系统能读到的内容。文本显示有无 BOM，以及更像 UTF-8 还是 GBK。
- **HTTP 请求调试**：位于「网络工具」。按分组保存请求。参数写成一行一个 `key=value`。POST 可以是这些参数、JSON、XML，或自己填写 MIME 的原文。列表在程序旁的 `httpdbg.json`。还没有示例时会加上分组「测试」，里面是本程序 `127.0.0.1:1224` 的状态、简繁、拼音、USB ID、货币和文本 Base64。删掉并保存后不会再加回来。
- **MIDI 合成器**：鼠标或电脑键盘弹琴，声音送到所选的 MIDI 输出。也可接 MIDI 键盘。能打开 MIDI 文件，改音轨、速度和音符后再保存。
- **录音机**：选择麦克风录音，也可以录正在播放的系统声音，或只录系统声音。设备列表只有麦克风，没有耳机这类播放设备。暂停后可以继续。停止后播放，或另存为 WAV。也可以打开、拖入已有的 WAV。
- **相机**：选择摄像头预览。预览优先用不高于 1280×720、帧率更高的模式。拍照保存 JPEG 或 PNG，录像保存 MP4（可选麦克风）。扫码识别画面里的二维码和条码，需要另装的 OpenCV 与 ZXing。同一个码至少隔 3 秒才会再显示一次。工具页「图像」里的相机可以预览拍照或用 ImageCapture 拍静帧，设备支持时可以变焦、开手电和对焦。扫码在浏览器提供时用 MediaStreamTrackProcessor 读帧，同一个码同样隔 3 秒再显示，并闪一下底色。每次扫出来会响 0.2 秒方波，音高和 8bit 合成器里的蜂鸣一样。不录像。
- **科学计算器**：工具菜单、托盘和工具页「计算」里的按键计算器。含三角函数、对数、乘方、开方、阶乘、百分数和内存，角度可在度和弧度之间切换。窗口无边框，整个窗口就是计算器，背景为黑色半透明。
- **桌面便笺**：工具菜单和托盘。无边框半透明窗口，可以写文字，也可以换成待办并勾选。右下角色块打开选色，旁边的角标用来改大小。关掉再打开，文字、待办、颜色和窗口位置都还在。
- **RTSP 测试服务器**：工具菜单和托盘。深色画面上画弹跳红球和绿色时间，用 `ffmpeg64` 里的 libx264 编成 H.264，默认 200 kbps，在所选端口提供 `rtsp://127.0.0.1:端口/live`（默认 8554）。**声音**打开时加一路 8 kHz PCMU 提示音；启动前关掉则没有这一轨，运行中关掉则停掉提示音。多个播放器可以同时看。工具页的 RTSP 播放可以填这个地址，勾选声音后播放 PCMU、PCMA 或 AAC。参数设置里的「RTSP转发」关掉后，这个网页请求不再接收。
- **自动按键**：向前台窗口连续发送按键或点击。默认 F6 只在这个窗口打开时开始和停止。间隔可调。前台是本程序时不发送。关掉窗口就停止。
- **窗口管理**：列出可见的顶层窗口。点选时用绿框预览，选中后可固定在前面或取消。

### 网页工具

这些网页工具出现在 **工具** 菜单对应分类里，名称后面标 `(web)`，和本机 HTTP 接口同一端口。主页和文件传输在分类上面，不加这个标记。标题栏的语言菜单跟桌面界面语言一致。`/sk/L.js` 按 `lang/*.toml` 的修改时间合成，这些文件没变就直接用已写好的 `web/L.js`。左边是分类，右边是工具；收藏下面有「全部」。按住 Ctrl 再点，用新标签打开。地址或收藏里已经没有的工具会忽略。

除了和桌面相同的识别、语音、二维码、拼音、简繁、历法、注音，页上还有：相机（预览拍照、静帧、变焦、扫码）、浏览器小模型、RTSP 播放（H.264，可选声音）、MD 阅读器（拖入预览）、文本转换、哈希、科学计算器、正则、单位换算（含汇率）、进制、日期计算、计时、世界时钟、函数图像、图片转 ICO、占位图、随机颜色、CSS 渐变、HTML 界面预览、画板、8bit 合成器、生成测试数据和聊天室。取色可以拖色板，也可以从屏幕上吸一个像素。画板的画笔会补上快速移动丢掉的点，触控笔还会走系统墨迹。浏览器小模型用桌面 Chrome 自带的本地模型做语言检测、翻译、摘要、改写、校对和自由提问，模型按站点单独下载。同一张卡片还可以用浏览器的 speechSynthesis 朗读，以及 webkitSpeechRecognition 听写。中文分词用 Intl.Segmenter，按词、句或字素切开，每行一段。聊天室在进入前填昵称，进入后 Ctrl+V 可粘贴图片或文件。点聊天里的图片会用本机的 Viewer.js 放大查看，没有过渡动画。世界时钟默认列出常用地区的本地时间，也可以再选一个地区。改输入后，不少文字工具会直接出结果。

「信息查询」分类里有 Unicode、ASCII、GBK 码表、摩斯码、颜色表、本机信息，以及常见 USB ID 列表。本机信息列出这个浏览器能读到的版本、屏幕、内存、键盘和处理器压力。读取每一块屏幕和离开检测要点一下才会询问权限。列表给出厂家、产品和型号，点一行再向本机 `/api/usb` 补上接口。桌面 **工具 → 信息查询** 放词典和系统信息。端口占用在 **工具 → 网络工具**。DNS 记录、端口测试、本机网络、网络唤醒和网络发现都在网络工具窗口里。

## 安装、语言与更新

精简包不含模型和大型运行库，自带 `7za.dll` 和 `License.7za.txt`，用来解压 7z。截图、标注、长截图、系统 OCR、系统语音、系统 H.264 录屏、上面列出的大部分工具、文件传输和投屏的电脑端，安装后即可使用。系统 OCR、Windows 语音识别和 Windows 语音合成，还要操作系统里已经有对应语言；缺少的可在安装窗口的 **Windows OCR/语音** 里安装。

条码、ONNX 文字识别、离线语音、人脸、本地中英翻译、词典、PDF、FFmpeg、CUDA 或 DirectML，在 **帮助 → 安装功能** 里勾选后安装或卸载。打开时已装的项是勾上的，将要新增和将要删除会分开显示。用到尚未安装的组件时会提示。语音包在单独的一页。Chrome 页可以查询、安装和卸载本程序隐藏 Chrome 的翻译语言包和离线语音包，安装过程中显示下载进度，不改日常浏览的用户数据。推理可用 CPU、NVIDIA CUDA 或核显 DirectML；没装加速库时用 CPU。

**参数设置 → 常规**里可以关掉某一类功能。关掉后隐藏对应页面，并停用热键、托盘入口和相关接口。界面语言在菜单栏或同一页切换，已有中文、英文、日文、韩文、德文、西班牙文、法文、葡萄牙文、俄文，缺的句子回退中文。

**帮助 → 检查更新**在启动时也会按间隔检查。有新版本时列出当前版本之后的每一版说明，可切换中文或英文，再更新或忽略。把更新的 `screenkit_版本.7z` 放在程序目录，启动或再点一次检查更新时会询问是否用它更新。连不上 GitHub 时，检查更新会提示可以把新版本的 7z 放到程序目录，再点一次检查更新。**帮助 → 诊断**查看各项是否就绪。**帮助 → 内存占用**可看占用，并卸载已加载的模型。

## 运行

Windows 10/11（x64），需要 [.NET Framework 4.8](https://dotnet.microsoft.com/download/dotnet-framework/net48)。

本机 HTTP 默认端口 1224。勾选允许局域网访问后，同一局域网可连接；否则只对本机开放。文件传输、网页工具和投屏共用这个端口。命令行可批量识图、列出模型，或做几项自检。
