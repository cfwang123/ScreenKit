# ScreenKit

Windows 桌面工具（`ScreenKit.exe`，界面标题「屏幕截图工具」）：截图识别、标注、录屏、语音、翻译、词典、人脸，以及和安卓配套的传文件、投屏。本机还有 HTTP 接口和浏览器工具页。

**当前版本：1.0.28** · [发布包](https://github.com/cfwang123/ScreenKit/releases/latest) · [更新日志](CHANGELOG.md) · [English](README.md)

## 截图与识别

- **截图识别**：热键或菜单框选区域，识别文字和条码；可换识别引擎，识别后可叠字翻译。
- **截图标注**：框选后画矩形、椭圆、箭头、画笔和文字，完成时复制为图片、文件或路径。
- **重复上次截图**：热键或菜单按上次框选的区域再截一次。
- **长截图**：点选可滚动窗口，自动滚动并拼接成一张长图。
- **截图历史**：缩略图浏览保存目录里的图，可平移、缩放、标注和复制。超过保留天数的图在启动时以及之后每 24 小时在后台删掉。
- **文字叠加**：把识别出的文字叠在图上，可拖选和复制。
- **剪贴板**：粘贴图片后直接识别、标注或保存。
- **PDF 工作台**：打开 PDF 分页识别，改字后导出可检索 PDF。

## 录屏

**捕获 → 录屏** 或 **GIF 录屏**：单击窗口，或拖拽框选。

- 红框画在选区外，开始前可改大小和比例，控制条可拖动和收起；录制中可改声音来源或关掉声音。
- **区域录屏**：录成 MP4，可录系统声、麦克风或两者，可叠加鼠标和点击高亮。
- **GIF 录屏**：同一套选区，录成无声 GIF，可调帧率和调色板。
- **录屏选项**：帧率，以及和截图一样的「限制较短边」。

## 语音、翻译、词典、人脸

- **语音识别**：实时字幕，可用离线或流式模型。
- **语音合成**：Windows、SAPI、离线语音、联网的 Edge 自然语音，以及本机 Chrome 的语音。Chrome 只列出已安装的语言。页上的 Chrome 模型安装会用本程序的专用配置打开 Chrome，进入模型页，已安装的语音可以试听一句。**参数设置 → 语音合成**是一张按语言排列的发音表（引擎、发音人、语速）。中文、日语、韩语、英语始终在表里，其它语言可以添加或删除。词典词条发音，以及划词浮窗朗读选「自动」时，用这一行。
- **语音输入**：热键开始和结束，把识别结果送进当前输入位置。
- **对话**：接已配置的 LLM，气泡对话，可麦克风输入和朗读。
- **LLM 日志**：看最近约 1000 次请求的模型、耗时，以及请求和响应。
- **翻译**：本地 ONNX、已配置的 LLM 或本机 Chrome。源语言选「自动」时按母语与学习语言互译，翻译页和小窗会显示判断出的方向，也能另选引擎和模型。Chrome 的语言下拉只列出已安装的语言包，页上的 Chrome 模型安装同样用专用配置打开模型页。
- **人脸**：检测和比对，可选关键点和性别年龄。
- **中文转拼音**：汉字转不带声调的全拼，或每个字一个小写首字母。
- **五笔、日语、韩语输入法**：用候选条在本程序或其它程序里输入。日语按词典补上汉字写法，以及动词和一类形容词的活用。读音只打到一半时，后面还能接上的词也会进候选。旧的输入法词库在 **帮助 → 安装功能** 里标成有新版本，可以重装或卸载。**工具** 菜单开启，托盘切换语言；快捷键、语言开关和词库在 **参数设置 → 输入法** 里设置（关掉的语言不进切换循环）。
- **简繁转换**：上面简体、下面繁体，繁体接近台湾用字。
- **日文注音**：把日文句子转成读音，可按词或逐字。
- **历法**：公历换农历（干支、闰月），以及日本、民国、希伯来、伊斯兰、波斯等历法。

### 词典

主窗口或 **工具 → 词典**。查汉语、英语、日语、韩语。

- 语言筛选：全部、汉语、日语、韩语、英语。
- 纯拉丁输入会把日语 romaji 转成平假名、韩语罗马字转成谚文再查，如 `watashi`、`hanguk`。
- 词条有读音、词性、义项、词组和例句，都能发音；**导出**写出这次搜索的全部词条。
- 在词条里双击、拖选或右键会弹出查词浮窗，最多 100 条。词典里始终可以划词。
- **参数设置 → 词典**可改一次列出的条数、数据库保持时间和划词浮窗。
- 词典热键默认是空的：不在主窗口时唤出并切到词典，已经是主窗口时隐藏。
- 网页词典是单独一页 `/dict`，在工具页的「文字」分类里点卡片打开，Ctrl+点击开新窗口，查词、四种语言、发音和导出与窗口里相同。
- **划词浮窗**在词典页、**参数设置 → 词典**或托盘打开，默认关闭；打开后在本程序或其它程序里拖选或双击文字就弹出查词浮窗，不抢焦点。没查到词时窗口大小和有词条时一样。选区里有单词不会出现的标点，或比一个单词更长时，只弹出、不查词典。语言栏右侧的**翻译**两边默认都是自动：原文是母语就译成学习语言，否则译成母语；改语言后要点一次翻译。原文可以改，旁边标出实际的源语言和目标语言。切换词典语言或翻译时宽度不变。右下角可拖动改大小，空白处可拖动位置；大小在关闭程序时记住，下次打开沿用。语言栏还有**朗读**：按句读出当前文字，读到哪句就高亮哪句，可选引擎（含 Chrome）、语速、语言和发音人。引擎选「自动」时用**参数设置 → 语音合成**里这一语言的引擎、发音人和语速。停在这一页时浮窗不会自动关掉，也不接收新的划词。

## 文件与投屏

### 文件同步

电脑打开 **文件同步**，手机与电脑在同一局域网。

- 列表是程序旁的 `sendfile/`，只看这一层：可列表或缩略图、框选多选、剪切复制粘贴、删除到回收站。
- 拖文件进列表放进接收目录，拖到下方区域发给手机；手机分享或上传都写到 `sendfile/`。
- **网页管理**用同一端口：电脑开 `/files`，手机开 `/m`，登录后可上传、建目录、改名和删除。

### 投屏

本程序运行时就接收投屏，可在参数里关掉；**托盘 → 工具 → 投屏** 打开投屏页。同一 Wi-Fi，不要开访客隔离。

- **电脑投到电脑**：选已保存的电脑、搜局域网或手填 IP，默认把画面限制在 1000×1000 以内。
- **手机投到电脑**：手机应用里选已保存的电脑或搜局域网，可走局域网或 USB（调试或配件）。
- 接收窗不置顶，画面可适应窗口或铺满，关闭即断开，投屏中可改画质和声音来源。

## 工具

- **图片格式转换**：批量转 JPG、PNG、PNG 调色板、BMP，可限制较短边、旋转和镜像。
- **视频批量转换**：批量转到 MP4、MKV 或 WebM，可限制较短边、保留声音。
- **视频转 GIF**：选起点和终点，转成无声 GIF，可调帧率和调色板。
- **字符画**：「模式」下拉选明暗 ASCII、点阵阴影或几种线条画法；全色字符画在命令行窗口里看。
- **像素画**：选好宽高后在格子上作画，旁边按真实像素预览，可复制或保存 PNG。
- **字符点阵提取**：把字画成点阵，导出 C 数组、十六进制或点阵文本。
- **二维码 / 条码生成**：生成 QR、Data Matrix、Code 128/39、EAN、UPC。
- **批量重命名**：手改目标名或用 `%1`、`#` 这类规则，可按名称或日期排序。
- **快速复制**：复制、剪切、删除到回收站，或做成符号链接、硬链接，可注册资源管理器右键菜单。
- **校验哈希**：算 MD5、SHA-1、SHA-256，可粘贴期望值比对。
- **文本小工具**：Base64、URL、十六进制、转义、大小写、空白、字数和 JSON 美化等。
- **MD 阅读器**：打开或拖入 Markdown（指向它的快捷方式也行），用系统自带的 IE11 内核显示；可切换明亮、暗色、米黄、护眼、午夜蓝主题，点击图片放大查看，可导出为 Word（需装 Word）或 PDF（用 Edge/Chrome 打印）。
- **Word/PDF 转 MD**：把 .docx 或文本型 PDF 转成 Markdown，可预览、复制或保存；文档里的图片抽到所选目录（默认 `images/001.png`，可用 `{name}` 换成文档名），PDF 文字用已安装的 PDFium 提取，扫描版请先用 PDF 识别。
- **密码生成器**：按长度和字符种类生成密码，也可把一句密码交给 LLM 译成其它语言再拼出来。
- **网络工具**：诊断、IP 扫描和端口扫描，含 Ping、域名解析、网络唤醒、路由跟踪等。
- **网络端口占用**：列出正在使用的 TCP、UDP 端口和对应进程，可打开所在位置。
- **系统信息**：系统、USB、串口、打印机、声音、字体、显示器、摄像头、蓝牙、磁盘和外设等。
- **系统工具**：只读列出进程、环境变量、启动项、已安装程序、服务、补丁和商店应用，也能查文件占用和文件关联。
- **性能监控**：无边框小窗显示 CPU、GPU、内存、网络和磁盘，可置顶和改更新间隔。
- **文件分析**：按文件头判断类型，看版本、图片、媒体和文本编码。打开 EXE 或 DLL 时多出一页，可看节、导入、导出、签名和 .NET 公开类型。
- **HTTP 请求调试**：按分组保存请求，参数一行一个 `key=value`，可发 JSON、XML 或原文。
- **MIDI 合成器**：鼠标或电脑键盘弹琴，可打开、修改和保存 MIDI 文件，并显示实时波形。
- **录音机**：录麦克风、系统声音或两者，停止后播放或另存 WAV。
- **相机**：选择摄像头预览、拍照、录像，也能扫描二维码和条码。
- **科学计算器**：无边框计算器，含三角函数、对数、乘方、开方、阶乘和内存。
- **桌面便笺**：无边框半透明便笺，可写文字或待办，内容和位置都会记住；标题栏图钉可把便笺置顶，状态也一并记住。
- **RTSP 测试服务器**：把弹跳画面推成 H.264，在所选端口提供 RTSP 地址。
- **自动按键**：向前台窗口连续发送按键或点击，默认 F6 只在窗口打开时开关。
- **窗口管理**：列出可见的顶层窗口，可固定在前面或取消。

## 热键

可在参数里修改。热键字符串留空表示关掉。

| 热键 | 作用 |
|------|------|
| `Ctrl+Alt+O` | 呼出或隐藏主窗口 |
| `Ctrl+Alt+Q` | 截图标注 |
| `Ctrl+Alt+G` | 重复上次截图区域 |
| `Ctrl+Alt+W` | 截图并识别 |
| `Ctrl+Alt+V` | 语音输入，再按结束 |
| `Ctrl+Alt+B` | 实时字幕 |
| `Ctrl+Alt+T` | 呼出或隐藏翻译小窗 |
| `Ctrl+Alt+P` | 切换截图复制方式：图片、文件、路径 |
| `Ctrl+Alt+H` | 在浏览器打开 web 工具主页 |

## 安装、语言与更新

精简包不含模型和大型运行库，自带 `7za.dll` 用来解压 7z。截图、标注、长截图、系统 OCR、系统语音、系统 H.264 录屏、上面列出的大部分工具，以及文件传输和投屏的电脑端，装好就能用；系统 OCR 和系统语音还要操作系统里已有对应语言。

条码、ONNX 文字识别、离线语音、人脸、本地中英翻译、词典、输入法、PDF、FFmpeg、CUDA 或 DirectML 在 **帮助 → 安装功能** 里勾选安装或卸载，用到没装的组件时会提示。

**参数设置 → 常规**可以关掉某一类功能，界面语言在菜单栏或同一页切换（中文、英文、日文、韩文、德文、西班牙文、法文、葡萄牙文、俄文）。**帮助** 菜单里可以检查更新、看诊断和内存占用。检查到新版本时，列出当前版本到新版本之间各版的说明，点版本号看该版，也可以看全部。

## 运行

Windows 10/11（x64），需要 [.NET Framework 4.8](https://dotnet.microsoft.com/download/dotnet-framework/net48)。

本机 HTTP 默认端口 1224，勾选允许局域网访问后同一局域网可连接；文件传输、网页工具和投屏共用这个端口，`POST /api/ocr` 与 Umi-OCR 文字识别兼容。设定端口打不开，或关掉 HTTP 接口时，改在只接受本机访问的随机端口上提供工具页和 HTTP 接口，菜单和按钮打开网页时用这个端口。
