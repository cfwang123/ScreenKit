# ScreenKit

Windows 桌面工具（`ScreenKit.exe`，界面标题「屏幕截图工具」）：截图识别、标注、录屏、语音、翻译、词典、人脸，以及和安卓配套的传文件、投屏。本机还有 HTTP 接口和浏览器工具页。

**当前版本：1.0.20** · [发布包](https://github.com/cfwang123/ScreenKit/releases/latest) · [更新日志](CHANGELOG.md) · [English](README.md)

![主界面](docs/1%20screenshot.png)

关掉主窗口会进托盘。托盘单击与主窗口热键相同：已在前面就隐藏，否则显示到最前。

## 截图与识别

- **截图识别**：框选后按结果区的 OCR 或条码来识别。未另选模型时用 Windows 系统 OCR，不加载 ONNX，也不需要 OpenCV。装了 ONNX 模型后可换引擎。识别结果可交给已配置的 LLM 做叠字翻译。
- **截图标注**：矩形、椭圆、箭头、画笔、文字，也可以不选工具。下次框选沿用上次的工具。完成时可复制为图片、文件或路径，并记住这次的选择。
- **长截图**：点选可滚动窗口，自动滚动后拼接，按当前复制方式写入剪贴板。不识别，也不需要 OpenCV。
- **截图历史**：用缩略图列出保存目录里的图，可预览、缩放和标注。保存位置在参数设置里改。
- **文字叠加**：在画面上拖选一块文字，Ctrl+C 复制。点空白取消。
- **剪贴板**：可粘贴图片再识别。菜单和托盘能切换截图完成时复制图片、文件还是路径。
- **PDF 工作台**：**工具 → PDF 识别工作台**。分页识别、改字，导出可检索 PDF。

## 录屏

- **区域录屏**：单击窗口或拖拽框选，在选区外的控制条上开始、暂停、停止。可录系统声、麦克风，或两者。可叠加鼠标和点击高亮。默认用系统 H.264 写成 MP4，不用 FFmpeg；也可选 x264、x265、AV1。
- **GIF 录屏**：同一套选区。采集后可调帧率、缩放和调色板，再保存无声 GIF。采集本身不用 FFmpeg。

## 语音、翻译、词典、人脸

- **语音识别**：实时字幕。未保存离线模型时用 Windows 系统识别。离线模型在安装功能里下载。
- **语音合成**：Windows 语音、SAPI、离线语音，以及联网的 Edge 自然语音。没有已保存的引擎时，优先用本机 Windows 语音，否则用 Edge。仅 32 位的经典发音人经旁边的 `x86host.exe` 调用。
- **对话**：接已配置的 LLM。气泡界面，可清空、用麦克风输入、朗读或自动朗读。
- **LLM 日志**：主界面列出最近的请求，可查看模型、token、耗时，以及请求和响应。
- **翻译**：本地 Opus-MT 模型，或已配置的 LLM。来回翻译在结果重复时停下。**工具 → 翻译小窗**可对原文和译文发音。
- **词典**：主窗口查汉语、英语、日语、韩语。每条有词头、释义，可发音；词条里有读音、词性、义项、词组和例句。可把这次搜索全部导出。发布包不含词典，在 **帮助 → 安装功能** 下载。
- **人脸**：检测和比对，可选关键点、性别年龄。模型在安装功能里下载。
- **中文转拼音**：不带声调，或只要首字母。常见多音词有词表，用户词表可覆盖。
- **简繁转换**、**日文注音**、**历法**：简繁走系统接口；注音需要本机日语支持；历法含农历以及日本、民国、希伯来、伊斯兰、波斯等。

## 文件与投屏

- **文件同步**：与手机互传文件和文本。电脑上浏览程序旁的接收目录，可剪切、复制、粘贴、删除。手机已连接时，可把文件发到手机。浏览器也可管理：电脑打开文件页，手机打开精简页。手机安装包可在这一页检查并下载。
- **投屏**：把本机画面投到另一台电脑，或接收手机画面。同一局域网即可；也可用 USB 调试或 USB 配件。发送前先框选区域，可选声音来源。接收窗口可适应或铺满。

## 工具

菜单 **工具** 里还有这些，多数不另装组件：

- **图片格式转换**：批量转 JPG、PNG、BMP 等，可缩小较短边、旋转、镜像。不装 OpenCV 也能转常见格式。
- **视频批量转换**、**视频转 GIF**：需要 FFmpeg，可在安装功能里下载。
- **字符画**：纯 ASCII，或在命令行窗口里画全色。
- **字符取模**：把字符画成点阵，导出 C 数组或十六进制。
- **二维码 / 条码生成**：QR、Data Matrix、Code 128 等，可选在图下写原文。
- **批量重命名**：用 `%1`、`#` 这类规则生成新文件名。
- **快速复制**：复制、剪切、删除，或做成符号链接、硬链接。可注册到资源管理器右键。
- **校验哈希**、**文本小工具**（Base64、URL、编码、JSON）、**密码生成**。
- **网络工具**：Ping、域名解析、WHOIS、路由跟踪和定位。
- **网络端口占用**：列出正在使用的 TCP、UDP 端口和对应进程。
- **系统信息**：计算机、处理器、显卡、磁盘、网络、USB、串口、打印机和声音设备。只读。
- **HTTP 请求调试**：保存并发送 GET / POST。
- **MIDI 合成器**：用键盘或鼠标弹琴，也可打开、修改并保存 MIDI 文件。
- **自动按键**：向前台窗口重复发送按键或点击。
- **窗口管理**：把选中的顶层窗口固定在前面，或取消。

**网页工具**与托盘里的入口相同，和本机 HTTP 接口同一端口。左边是分类，右边是小工具，例如文字识别、语音、二维码、文本转换、哈希、计算器、正则、单位换算、颜色、计时、函数图像和聊天室。地址只认当前仍在的工具。

## 热键

可在参数里修改或留空关掉。

| 热键 | 作用 |
|------|------|
| `Ctrl+Alt+O` | 呼出或隐藏主窗口 |
| `Ctrl+Alt+Q` | 截图标注 |
| `Ctrl+Alt+W` | 截图并识别 |
| `Ctrl+Alt+V` | 语音输入，再按结束 |
| `Ctrl+Alt+B` | 实时字幕 |
| `Ctrl+Alt+T` | 翻译小窗 |
| `Ctrl+Alt+P` | 切换截图复制方式 |

## 安装与语言

精简包不含模型和大型运行库。截图、标注、长截图、系统 OCR、系统语音、录屏（系统 H.264）、上面列出的大部分工具、文件传输和投屏电脑端，安装后即可使用。系统 OCR 和 Windows 语音还要操作系统里已经有对应语言。

条码、ONNX 识别、离线语音、人脸、本地翻译、词典、PDF、FFmpeg、CUDA 或 DirectML，在 **帮助 → 安装功能** 里勾选后安装。用到尚未安装的组件时会提示。

界面语言在菜单栏或 **参数设置 → 常规** 切换。已有中文、英文、日文、韩文等。**帮助 → 检查更新** 可查看之后各版的说明并安装最新包。

## 运行

Windows 10/11（x64），需要 [.NET Framework 4.8](https://dotnet.microsoft.com/download/dotnet-framework/net48)。推理可用 CPU、NVIDIA CUDA 或核显 DirectML。

更细的用法、接口和编译见 [README.zh.md](README.zh.md)。手机端见 [android/README.md](android/README.md)。
